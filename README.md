# 🎣 Phishing Awareness Training

## 🛡️ CodeAlpha Cyber Security Internship Project

This project was created as part of the CodeAlpha Cyber Security Internship to educate users about phishing attacks, social engineering techniques, fake websites, and cybersecurity best practices.

---

## 📖 Project Overview

Phishing is one of the most common cyber attacks used to steal sensitive information such as passwords, banking details, OTPs, and personal data.

This awareness training presentation helps users:

- Understand phishing attacks
- Identify fake emails and websites
- Recognize social engineering tactics
- Learn prevention methods
- Improve cybersecurity awareness

---

## 🎯 Objectives

- Understand phishing attacks
- Learn different phishing techniques
- Identify phishing emails
- Detect fake websites
- Follow cybersecurity best practices
- Increase awareness against online scams

## 🚨 Common Warning Signs

- Suspicious sender email
- Urgent requests
- Grammar mistakes
- Unknown links
- Requests for passwords or OTPs

---

## 🔒 Prevention Tips

- Verify sender identity
- Enable Two-Factor Authentication (2FA)
- Use strong passwords
- Avoid suspicious links
- Keep software updated
- Check website URLs carefully
